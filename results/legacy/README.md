# Legacy Pong trial material

This folder contains older plotting scripts and root-level generated outputs that were kept for reference while cleaning up `main/pong_trials`.

- `plots_old/`: earlier one-off plotting scripts for generated Pong metrics.
- `old_root_outputs/`: generated CSV and PNG outputs that previously lived in the `main/pong_trials` root.

The active simulation entry points, environment modules, current plotting folders, and HPC submission files have not been moved in this pass.
